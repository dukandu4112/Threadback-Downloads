# Threadback

**Your train of thought has a return ticket.**

A Windows desktop app for interrupted work. Save your last thought, the next tiny
action, a blocker, and a breadcrumb. Return Mode helps you pick up where you stopped.

This repository distributes the app and user documentation. Threadback application
source and development history remain private. Automatic GitHub source-code
archives for this repository contain these documents, not the application source.

## Downloads

[Download Threadback for Windows](https://github.com/dukandu4112/Threadback-Downloads/releases/latest).
Choose **Threadback-1.0.1-Windows.zip** under Assets.
The ThirdPartySources ZIP contains upstream dependency sources, not application source.

The Windows package includes Java. Extract the whole ZIP, then open
`Threadback/Threadback.exe`. Keep the app and runtime folders together.

## Included features

- Capture, edit, search, park, finish, reopen, and resume work.
- Earlier capture history with safe reuse.
- Local storage, backups, validated restore, and recovery snapshots.
- Keyboard shortcuts and built-in Help.

[Getting started](GETTING-STARTED.md) · [Support](SUPPORT.md) · [Third-party notices](THIRD-PARTY.md)

Notes and backups stay on your device and are unencrypted. The app has no account,
cloud sync, telemetry, or background file monitoring. The portable Windows x64
package is unsigned. macOS and Windows ARM packages are not provided.

The separate third-party source asset contains upstream dependency sources only.
Its licenses and notices do not grant a license to Threadback application source.
