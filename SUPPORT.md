# Support

Use this repository's Issues tab for reproducible bugs and usability feedback.

Include the Threadback release version, Windows version and architecture, exact steps, expected behavior, actual behavior, and error text. Use synthetic example notes. Remove usernames, personal paths, URLs, and other private details from screenshots or logs.

Do not upload `threads.db`, backups, credentials, or private work notes. For recovery problems, preserve the original backup and recovery snapshots before trying changes.

No response-time or maintenance-period commitment is made. Feature requests do not change the completed v1.0 scope automatically.

For a suspected security problem, do not include exploitable details or private data in a public issue. Use GitHub's **Report a vulnerability** option if the repository exposes it. If unavailable, ask for a private reporting channel without posting the details. No dedicated support mailbox has been configured for Threadback.
