# Validation scope

Threadback 1.0.1 passed 36 tests on each of Linux and Windows, including 12 JavaFX
interaction tests. Native Windows checks passed capture, persistence,
backup/restore, picker and confirmation cancellation, recovery snapshots,
reopening and saved-thread resume. The native checks also passed from the final
extracted Windows ZIP.

The distribution audit checked expected contents, archive integrity, upstream
notices, dependency source archives, component inventory and SHA-256 checksums.
The application source and development history remain private.

Human screen-reader evaluation, macOS, Windows ARM, every individual Windows
device, and long-duration field use are not claimed. The package is unsigned.
